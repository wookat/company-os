# Web → 小程序/APP 功能对照表

对照基准：https://zhenti.zalize.com/app2/ （build dd7b90f）+ 旧版 /app。
小程序 = Taro weapp 编译产物；APP = 同一套代码的 H5 产物装壳（Capacitor/WebView）或 Taro RN 路径（见 README）。除注明外，小程序与 APP 行为一致。

| # | Web 功能 | 接口 | 小程序/APP 实现 | 状态 |
|---|---------|------|----------------|------|
| 1 | 每日一题（先想再揭晓） | GET /api/real/daily | 首页「每日一题」卡：题干+ABCD 分行，揭晓前隐藏答案 | ✅ 对等 |
| 1a | 揭晓即打卡（当天不重复） | POST /api/checkin | 揭晓时检查今日打卡状态，未打卡才调用 | ✅ 对等 |
| 1b | 揭晓计数 | POST /api/daily-reveal?src=app | 揭晓时上报 | ✅ 对等 |
| 1c | 解析按选项分行 | — | 解析按 A/B/C/D 项拆分分行展示 | ✅ 对等 |
| 1d | 这个考点直练 | GET /api/real/kp?name= | 揭晓后展示直练按钮，组卷进答题页 | ✅ 对等 |
| 2 | 打卡分享图 | — | ShareCard 组件：640×800 Canvas，蓝紫渐变+大数字+域名；小程序 canvasToTempFilePath+保存相册授权（拒绝后引导开设置）；H5/APP canvas.toDataURL 下载 | ✅ 对等（平台差异：小程序存相册 / H5 下载 PNG） |
| 2a | 成绩分享图 | — | 成绩页「晒成绩」同上；正确率 <40% 或击败率 <20% 不显示「击败 X% 研友」，改评语口径 | ✅ 对等 |
| 3 | 新用户三步上手引导 | GET /api/stats | stats.attempts 为空时首页顶部展示 3 步卡（做最新卷→考点报告/错题本→每日一题打卡+开提醒），✕ 关闭写 Storage `zt_onboard_done:<uid>` 按账号记忆 | ✅ 对等 |
| 4 | 错题到期角标 | GET /api/wrongdue | TabBar 组件自取 {due}，错题本 tab 红色数字角标，99+ 封顶；切页（useDidShow/组件重挂）+ 回前台（H5 visibilitychange / 小程序 onAppShow）刷新 | ✅ 对等 |
| 5 | AI 补练闭环 | GET /api/kpdrill?name=、GET /api/materials/:id、POST /api/papers、GET /api/papers/:id | 考点页/报告页「AI 补练」→ drill 页选考点+题量（5/10 免费，15/20 会员，附加分析题选项）→ 生成；答题页对 status!=ready 每 5s 轮询，失败 toast 原因 | ✅ 对等 |
| 5a | 额度用尽明确提示 | 402 响应 / quota | 生成前本地校验 quota 并给出改选建议 toast；402 后端报错原样 toast | ✅ 对等 |
| 5b | 会员/额度展示 | GET /api/me | 我的页：PRO 徽标+到期日、今日模拟卷/快练剩余、去 AI 补练入口 | ✅ 对等 |
| 6 | 按考点选题 | GET /api/real/kps、/api/real/kp | 考点页：按科目分组 chips + 就地过滤输入框（空组隐藏），chip 热区 ≥40px；点击真题直练，AI 按钮进补练 | ✅ 对等 |
| 7 | 错题收藏 | GET/POST /api/favorites、DELETE /api/favorites/:id | 错题本收藏 tab（一期已有） | ✅ 对等 |
| 7a | 真题收藏 | GET/POST /api/realfav、DELETE /api/realfav/:id、GET /api/real/favpaper | 搜索结果 ☆ 收藏；「真题收藏」页列表+取消+「收藏自测卷」组卷 | ✅ 对等 |
| 8 | 分析题要点逐条自评 | GET /api/subjmemo、POST /api/subjmemo/hit | 背诵页要点展开后点「点我自评命中」切换 ✓，防抖 300ms 同步，与 Web 互通；显示想到 n/t | ✅ 对等 |
| 8a | 报告页周命中率 | GET /api/subjmemo (hits.u) | 报告摘要展示近 7 天要点命中率（n/t） | ✅ 对等 |

| 11 | 搜索：年份+题号直达 | GET /api/real/browse?year=、/api/real/subjective?year= | 搜索页支持 `2019 30` / `2019年第30题` / `2019-30`，直达卡展开答案解析；分析题引导到背诵页 | ✅ 对等 |
| 11a | 考点/关键词搜索 | GET /api/real/search?q= | 客观题结果（可展开答案/解析/收藏/考点直练）+ 相关分析题 | ✅ 对等 |
| 12 | 学习报告冲刺看板 | GET /api/stats、/api/kpstats、/api/wrongdue | 周摘要三格：做题道数/有作答天数/待复习错题；正确率趋势按作答日聚合、时间正序、Y 轴按 min–max 自适应缩放；薄弱考点列表带 AI 补练入口 | ✅ 对等 |
| — | 打印（Web） | — | 平台限制替代：分享图生成 PNG 保存/下载 | ⚠️ 替代方案 |
| — | 支付/开通会员（Web 跳支付页） | pay_enabled | 小程序内不做支付（微信虚拟支付合规限制），我的页展示会员状态；开通仍走 Web | ⚠️ 平台限制，注明 |

平台限制汇总：
- 微信开发者工具仅有 Windows/macOS 版，本 Linux 交付环境无法运行工具内截图；weapp 产物已 `npm run build:weapp` 编译通过，H5 端为同一套页面代码的真数据截图。
- 小程序保存相册需用户授权 scope.writePhotosAlbum，已实现拒绝后引导打开设置。
- APP 未做原生签名打包，接入路径（RN 编译 / H5 装壳）见 README。
