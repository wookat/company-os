# tiku.zalize.com 竞品调研：免费题库站在巨头夹缝中的生存空间

- 调研人：market-researcher（数据资产工厂）
- 日期：2026-08-01（时效敏感数据均为当日采集）
- 决策用途：判断 tiku.zalize.com（教资三学段 + 公务员行测 + 事业编公基，约 8362 道原创仿真题，免费/免登录/纯网页）是否有生存缝隙、往哪条产品线加码。
- 方法：一手实测优先（本机浏览器亲访各竞品站、走免费流程、截图存档），无法实测处用公开资料并标注。**限制说明：本机为海外 IP 且无中国手机号，所有需手机号实名注册的流程按任务要求记录后跳过**；粉笔网页题库（Angular SPA）在本环境报 JS 错误白屏、API 返回 401，未能进入登录后界面；offcn.com 主站对海外 IP 返回 403（以上均已截图/记录）。

---

## 一句话结论

**缝隙存在且明确**：巨头的"免费"都是获客漏斗——强制手机号注册、导流 App、解析/深度功能锁会员；纯网页、免登录、零广告、解析深度可读的题库在中文互联网几乎是空白（我们实测的 6 家无一做到），这就是 tiku 的定位。但缝隙窄在"题量与真题权威性"打不过粉笔（免费题库号称 240 万道），所以打法应是 **SEO 长尾 + 免登录体验 + 解析质量**，并向巨头覆盖弱的长尾考试线扩展，而不是正面拼公考主线。

---

## 竞品逐家拆解

### 1. 粉笔（fenbi.com / 粉笔App）——公考线上绝对霸主

- **形态与核心功能**：App 为主战场（注册用户超 7000 万、月活约 910 万、付费用户约 238 万）；免费题库号称超 240 万道，含历年真题、每日刷题、每周模考大赛、错题本、自动组卷。网页端题库为 Angular SPA，实测在本环境白屏（JS 报错）、题库 API 未登录返回 401——**网页端必须登录（手机号）才能刷题**（一手实测 + 公开资料，置信度高）。来源：https://www.fenbi.com/page/home ；用户/题量数据来源：http://www.xtrb.cn/syunf/2026-05/20/content_1122445.htm （媒体转引官方数据，置信度中）。
- **定价与变现**：免费题库获客 → 会员（第三方拆解：约 39 元/月、198 元/年档位，置信度低，未验证）→ 系统班 980～1280 元 → 线下班 5000～20000 元。会员/课程为主要收入。来源：https://jhco-op.com/post/6678.html （置信度低）、知乎 https://zhuanlan.zhihu.com/p/1903865068015317039 （置信度中）。
- **流量**：App Store 4.9 分/25 万评分；fenbi.com 第三方估约 170～260 万月访问（hypestat/mysite.info，置信度低）。流量大头在 App 与品牌词搜索。
- **口碑**：整体极好（"不买课也能用大量免费功能"是高频好评）；差评集中在课程涨价、协议班服务兑现。来源：App Store 评论页（一手可查）。
- **缺口/我们的机会**：网页端体验差且强制登录；免费题海面向"泛刷题"，**逐题深度解析（易错点、考点延伸）质量参差**；对非公考长尾线（教资只是副线）投入有限。

### 2. 中公（offcn.com / eoffcn.com 中公网校）——课程销售驱动，无真正的网页题库

- **形态**（一手实测，置信度高）：offcn.com 主站对海外 IP 直接 403；中公网校 eoffcn.com 可访问，导航里的"考试题库"实为 **SEO 文章列表**（"行测每日一练 7.31"之类的图文页，共 400+ 分页），"在线刷题"按钮直接跳 **App 下载页**。存在 tiku.offcn.com 但内容陈旧（搜索快照显示 2015 年试卷、测试数据"33333333真题"残留），基本弃维护（置信度中）。
- **定价与变现**：核心是卖课——网校会员"最低 42 元/年"起，课程 78～29800 元；曾以"协议班（不过退费）"闻名。变现完全不依赖题库。
- **流量**：全国分校 SEO 矩阵（bj.offcn.com 等省域站群）+ 品牌词 + 线下渠道；题库文章页本身就是 SEO 抓手。
- **口碑**：协议班退费纠纷是全网知名负面（黑猫投诉大量记录，置信度高）。
- **缺口**：**没有可用的网页刷题产品**；题库文章页做题体验为零（题目和答案分两篇文章）。任何"点开就能做题"的网页都比它体验好。

### 3. 华图在线（huatu.com / 华图在线App）——网页题库名存实亡

- **形态**（一手实测，置信度高）：huatu.com 首页"华图题库"入口指向 30fen.huatu.com（估分/模考系统），实测试卷列表为**空**（"没有想要的试题？切换筛选条件试试吧"）；真正的题库在"华图在线"App。分省站（如 ah.huatu.com/tiku/）残留部分历年模考页。
- **定价**：App 会员权益 2 年 696 元（官方课程页拆项，置信度高，来源：https://yn.huatu.com/zt/2023gkwxx/ ）；注册即为"会员"、等级制打折买课；申论一对一批改 180 元/次。变现同样以课程为主（980～29800 元班型）。
- **流量**：省域站群 SEO（资讯/公告类）+ App 商店；App Store 华图在线约 4.5 分级别，弱于粉笔（置信度中）。
- **口碑**：教师线 App（华图教师）评分 4.5、评论量不足粉笔/一起考教师零头（来源：https://www.100ec.cn/detail--6617968.html ，置信度中）。
- **缺口**：网页题库实质废弃；免费模考页面老旧、无解析深度。

### 4. 一起考教师（App，博文烁/17学堂出品）——教资垂类第一 App，但纯 App 形态

- **形态**（一手实测 + 公开资料）：官网 17kaojiaoshi.com 实测只是一个**空壳页**（仅版权行 + "请升级浏览器"，无任何网页题库）；产品完全在 App 内：游戏化闯关刷题、知识卡片、直播课，覆盖教资三学段 + 教师招聘（语数外音体美幼）。App Store 4.9 分、10.66 万评论、近 180 天下载约 48 万，是教资垂类下载量第一（来源：https://www.100ec.cn/detail--6617968.html ，置信度中；小米商店页 https://m.app.mi.com/details?id=com.tsingzone.questionbank ）。
- **定价与变现**：免费刷题 + 直播课获客，变现靠课程（笔试/面试班）与会员；主观题批改等锁付费（置信度中）。
- **流量**：App 商店 + 微信公众号/微博私域；**没有 web SEO 流量**（官网无内容可收录）。
- **口碑**：评分高；差评集中在客服推销、部分功能需付费解锁（App 商店评论，置信度中）。
- **缺口**：**整条 web 战线空白**——搜索"教资 科目二 练习题"这类词它完全不接流量；不想装 App、电脑端备考的用户无处可去（这正是我们教资三学段线的对位机会）。

### 5. 上学吧（shangxueba.com）——搜题+付费答案模式，广告式体验

- **形态**（一手实测，置信度高）：找答案（搜题）+ 题库（按证书分类的模拟卷）+ AI 搜题 + 课程。试卷页可看到卷面信息，点"考试模式/背题模式"立即弹**登录墙**，注册必须中国手机号 + 短信验证（已截图，按规跳过）。首页/题库页大量 App 引导与推广位。
- **定价**（一手，页面直读）：题库月卡 ¥15.8、季卡 ¥35.8、单科目卡 ¥75.8（"惊喜价"）；搜题按次/VIP。答案本身就是付费墙。
- **流量**：老牌 SEO 站（2009 年起），靠海量题目页吃长尾搜索词；第三方估月访问量级从 14 万到千万不等、口径混乱（hypestat 1170 万/月 vs netatlas 4844/日，**互相矛盾，均低置信，未验证**）。
- **口碑**：知乎/贴吧常见吐槽"答案要钱""会员到期题还没刷完"；自动续费类投诉在黑猫上属行业通病。
- **缺口**：体验为"答案付费墙 + 登录墙 + 广告"，与"想安静刷题"的用户利益直接冲突；题目质量靠采集/用户上传，解析多为一句话或无解析。

### 6. 考试资料网（ppkao.com）——同模式小站，搜题工具化

- **形态**（一手实测，置信度高）：首页即大搜索框（搜标题/搜题干/搜选项）+ 拍照/语音/截图搜题 + 桌面客户端 + "上传个人题库免费刷题"；题目详情页答案需登录/开通 VIP。覆盖考试极杂（建造、医学、教资、公务员、网课答案）。
- **定价**：VIP 会员（历史价约 30 元/月量级，用户"求合租账号"帖侧面印证嫌贵，置信度低）；来源：https://zhidao.baidu.com/question/306121091571513164.html 。
- **流量**：纯 SEO 长尾（每道题一个 URL）；第三方估从 4 万/月到 15 万 UV/日不等（statshow vs siteindices，**矛盾、低置信**）。
- **口碑**：工具型，无忠诚度；"答案锁 VIP"差评与上学吧同款。
- **缺口**：同上学吧——不是"刷题练习"产品，而是"查答案"生意；无体系化练习、无考纲结构。

### 7. 题库类小站（kaoshiji.cn / kaowang.cn 等）

- kaoshiji.cn：试卷列表 + 微信小程序刷题导流；kaowang.cn：在线做卷（本环境访问超时，**未验证**）。共同点：内容采集、无解析或解析极薄、页面老旧、变现靠广告/小程序。它们证明**长尾搜索流量确实养得活小站**，但没有一家在"解析质量 + 现代体验"上立足。

## 核心问题回答：巨头免费题量已很大，独立免费题库站还有没有生存缝隙？

**有，且缝隙就是巨头的商业模式本身**（置信度高，全部来自一手实测）：

1. **免登录**：6 家竞品全部要求手机号注册后才能真正做题/看答案。巨头必须收手机号（获客线索是其商业命脉），我们不必——这是结构性优势，不是暂时空窗。
2. **纯网页**：粉笔/华图/一起考教师都把重心压在 App，web 端要么登录墙要么废弃。搜索引擎来的用户（"教资科目二 模拟题 在线做"）落地即流失，没人接。
3. **无广告无推销**：所有竞品页面都在推课/推 App/弹客服。"安静刷题"本身是差异化。
4. **解析深度**：搜题站基本无解析；巨头海量题的解析参差。逐题"解析+易错点+考点延伸"在长尾题目上是稀缺品。
5. **长尾考试线**：巨头资源集中在国省考公考主线。**覆盖弱的长尾线**（依据实测观察 + 各家产品线排布推断，置信度中）：事业编各省公基（区县级考纲差异大）、特岗教师、教师招聘（非教资）、三支一扶、社区工作者、辅警/书记员、军队文职、乡镇公务员、普通话水平测试等——这些线搜索需求真实存在，但巨头只有 SEO 文章、没有可刷题库。

**风险与不利面（诚实评估）**：粉笔免费题量是我们的 ~290 倍且含真题；"仿真题非真题"在公考人群里信任门槛高；国内 SEO 依赖百度收录（本环境无法验证百度收录量，未验证）；无 ICP 备案域名在百度权重与部分场景（小程序）受限。

## 三条可执行打法建议（如无异议将按此执行）

1. **all-in 长尾 SEO 页而非首页品牌**：把每个知识点/考点做成独立可收录页（考点页 = 简介 + 该考点全部题目 + 深度解析），标题对准"XX考点+练习题/真题/例题"长尾词——上学吧/ppkao 证明题目页长尾流量模式成立，我们用"免登录直接做题 + 真解析"承接它们承接不住的用户。优先扩产巨头无题库产品的线：**事业编公基（分省）、特岗教师、三支一扶、普通话测试**。
2. **把"免登录/无广告/双模型核验"写成信任资产**：在每页页脚与 About 页明示"不收手机号、无弹窗、AI 命制+双模型核验+人工抽检"，并给每题展示核验标记；同时新增"真题风格对照说明"降低"非真题"信任门槛。对比页（"粉笔/上学吧 需要注册吗"类关键词）可做诚实对比内容吃品牌词长尾。
3. **变现按老板既定原则暂缓，先做留存钩子**：不加登录墙的前提下做轻留存——本地存储错题本/进度（无账号）、每日一练邮件/RSS 订阅、可分享的模考成绩页（带回流链接）。等日 UV 有量后再评估会员（对标上学吧 15.8/月的心理价位，但解锁的是"导出/组卷/AI 答疑"而非答案本身——答案永远免费，这是与搜题站的根本分界）。
