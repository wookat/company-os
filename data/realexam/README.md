# 考研政治历年真题客观题数据集（2010–2025）

结构化的考研政治客观题数据集：16 年 × 33 题（单选 1–16、多选 17–33），共 528 题。仅收录题干、选项与答案字母，**不含任何机构解析原文**。

## 文件与字段

每年一个文件 `data/realexam/{year}.json`，为 33 个对象的数组：

| 字段 | 说明 |
|------|------|
| `year` | 年份（考试年，如 2025 表示 2025 考研，2024 年 12 月开考） |
| `seq` | 题号 1–33 |
| `qtype` | `single`（1–16）/ `multi`（17–33） |
| `stem` | 题干 |
| `options` | `{A,B,C,D}` 四个选项 |
| `answer` | 答案字母（单选 1 个字母；多选 2–4 个字母，按字母序） |
| `subject` | 五科之一：马原·哲学 / 毛中特 / 史纲 / 思修法基 / 形势与政策 |
| `kp_name` | 映射到 `src/library.js` 官方考点库（109 个考点）中的考点名 |
| `kp_confidence` | `high` / `low`（自动映射拿不准时为 low） |
| `answer_disputed` | 来源答案存在分歧时为 1 |
| `third_party_material` | 题干引用第三方版权材料（诗词/漫画/对联/文学作品等）时为 1 |
| `sources` | 本题所用公开来源 URL 列表 |
| `answer_candidates` | 仅分歧题有：各候选答案 → 给出该答案的来源 URL |

## 来源与合规

- 全部来自免费公开网页/文件，无付费或需登录内容：
  中国教育在线（kaoyan.eol.cn）、新东方在线（kaoyan.koolearn.com）、233网校（233.com）、
  中国考研网（chinakaoyan.com）、中国研究生招生信息网（yz.chsi.com.cn）、
  人民网教育、新浪教育、新东方网（xdf.cn，含 word/PDF 版答案）、EduGo 2025 真题 PDF。
- 仅提取真题题干/选项/答案字母；各机构的【解析】、答案要点等版权文本一律剔除，未复制。
- 题干中引用的诗词、漫画、对联、文学作品节选等第三方版权材料以 `third_party_material=1` 标出（启发式正则识别，共 17 题）。

## 交叉校验方法

1. 每年选取 2–5 个独立公开来源，分别解析出题干、选项、答案。
2. 不同来源的选项顺序可能不同：程序先按选项文本相似度将各来源的答案字母**重映射到基准选项空间**后再比对，避免因选项排序不同造成的假分歧。
3. 全部来源一致 → `answer_disputed=0`；存在分歧 → `answer_disputed=1`，最终 `answer` 取多数票（平票取主来源），全部候选答案及其来源记录在 `answer_candidates`。
4. 自查：每年恰 33 题（16 单选+17 多选）、题干/四个选项均非空、单选答案恰 1 字母、多选 2–4 字母且按字母序、`kp_name` 均存在于 `src/library.js`。

## 考点映射

- 以 `src/library.js` 的 109 个官方考点（五科）为映射目标（文件顶部注释写"101"，实际包含 109 个考点条目）。
- 客观题采用"题号→科目"的常规卷面结构作为先验（单选 1–4 马原、5–8 毛中特、9–12 史纲、13–14 思修、15–16 形势；多选 17–21 马原、22–25 毛中特、26–28 史纲、29–31 思修、32–33 形势，个别年份略有浮动，故仅作加权而非硬约束），再按考点名称与描述的文本相似度自动打分选取最优考点。
- 打分不足或次优项过近的题标 `kp_confidence='low'`（共 257 题），建议出题使用前人工复核 low 题的考点归属。
