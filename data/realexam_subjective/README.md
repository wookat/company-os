# 考研政治历年真题·分析题（主观题）结构化数据集（2010–2025）

覆盖 2010–2025 共 16 年，每年第 34–38 题（马原 / 毛中特 / 史纲 / 思修法基 / 形势与政策），共 80 题。
供「真题工坊」分析题背题 / 自评功能使用。

## 文件与格式

- `data/realexam_subjective/{year}.json`：UTF-8，缩进 1，每个文件为 5 个对象的数组。
- 字段：

| 字段 | 说明 |
| --- | --- |
| `year` | 年份（2010–2025） |
| `seq` | 题号（34–38） |
| `subject` | 科目（34 马原·哲学 / 35 毛中特 / 36 史纲 / 37 思修法基 / 38 形势与政策，个别年份按实际题目归属） |
| `stem` | 材料原文（或概述）+ 设问，形如 `结合材料回答问题：\n<材料>\n(1)…\n(2)…` |
| `questions` | 设问列表（1–3 问） |
| `answer_points` | 参考答案要点，3–6 条、每条一句话，**全部为 AI 原创组织的表述，未复制任何机构参考答案文本** |
| `kp_name` | 映射到 `src/library.js` 官方考点库中最贴切的考点；选不出时为空字符串 |
| `kp_confidence` | 1（人工复核确认）或 0.5（低置信 / 选不出） |
| `third_party_material` | 材料摘编自第三方媒体报道 / 著作时为 1 |
| `sources` | 该年题面所依据的公开来源 URL |

注：考点库以仓库 `src/library.js` 当前版本为准（实测 109 条；任务描述中的“114 考点”与库文件条目数不一致，映射均取自现有库内条目）。

## 来源与校验方法

- 题面均取自免费公开网页/文字版：中国教育在线（kaoyan.eol.cn）、中国考研网（chinakaoyan.com）、233 网校公开真题页、新东方在线公开文字版、中公四川考研公开页、新文道公开页、EduGo 公开 PDF 等，逐年 URL 见各条目 `sources`。
- 每年题面以两个及以上独立公开来源交叉校验题号、设问与材料；OCR 错字（如“七火预备会议”→“七大预备会议”、“张福清”→“张富清”等）已修复；页码、推广语、站点水印已清除。
- 机构“参考答案/解析”文本一律剔除，不进入 `stem`/`questions`；`answer_points` 为基于教材知识点的原创要点式重述。
- 版权处理：材料引用第三方长篇报道/受版权保护文章的题（如 2018-34/37/38）以概述替代全文并标记 `third_party_material=1`；2020 年公开文字版未附完整材料，各题以简短概述代替（材料为官方活动/文件描述，`third_party_material=0`）；其余标 1 的题为摘编自公开媒体的短材料，保留考试原文摘编。
