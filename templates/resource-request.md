# 外部资源申请单（模板）

> 立项时一次性提交给老板；提交后不等待，缺口处用替代方案先行（CHARTER §3.7）。

| # | 资源 | 用途 | 紧急度 | 缺口期替代方案 | 老板操作指引 |
|---|---|---|---|---|---|
| 1 | 例：Paddle 支付账号 | 订阅收费 | 上线前需要 | 免费模式先行 + 支付桩 | 注册链接 + 需提供的 key 名称 |
| 2 | 例：XX API key | 数据源 | 开发期需要 | 公开样例数据 | 控制台链接 + 建议权限范围 |

要求：
- 每项必须写「老板操作指引」——给到可直接照做的链接/命令，不写模糊请求
- 建议最小权限、专用账号
- 资源到位后由 project-lead 注入并替换替代实现，记录在项目日志
