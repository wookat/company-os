# 项目一页纸（模板）

| 项 | 内容 |
|---|---|
| 项目名 | |
| 一句话目标 | 为谁解决什么痛点，做到什么程度 |
| 范围 | 本期做什么 |
| 非目标 | 明确不做什么（必填） |
| 里程碑 | M1 骨架可跑 / M2 主流程完整 / M3 四道把关通过 / M4 上线+竞品对标 |
| 组队名单 | 角色 × 实例数（来自 roles/） |
| 外部资源清单 | 需老板提供的资源（支付/API key/账号/域名），逐项列出 + 缺口期替代方案（桩/沙箱） |
| 竞品对标对象 | 验收前逐项对比的 2~3 个同类产品 |
| 主要风险 | 风险 + 预案 |
