# 真题工坊 · 三端 UI 原型设计说明

> 交付物：`proto-weapp.html`（微信小程序端）、`proto-app.html`（移动 APP 端）、`proto-desktop.html`（桌面端），均为单文件 Tailwind CDN 原型，浏览器直接打开即可点击跳转模拟主动线。关键页截图见 `shots-v4/`。
> 信息架构基于现网 https://zhenti.zalize.com/app 走查（renderExam/renderList/renderResult/viewHome/viewWrong/viewAccount 等视图），功能元素一一对应，未改产品代码。

## 1. 共用设计语言（三端一致）

沿用已有粉笔风设计体系（详见 `DESIGN-SPEC.md`），三端共用同一套 token：

| Token | 值 | 用途 |
|---|---|---|
| brand-500 | `#3D7FFF` | 主操作、选中态、进度、tab 激活 |
| rose-500 | `#F43F5E` | 真题/新卷标识、错题、到期提醒（真题玫红） |
| ok-500 | `#00B578` | 正确、打卡、完成态 |
| warn-500 | `#FFA716` | 标记待查、待复习、中等得分率 |
| streak-500 | `#FF7A2F` | 连续学习/温习激励 |
| page | `#F5F7FB` | 页面底色（浅蓝灰） |
| ink / ink-2 / ink-3 | `#1E2330 / #5A6472 / #9AA3B2` | 三级文字 |

共用组件规则：
- 卡片：白底 `rounded-2xl` + `border-black/5` + 浅投影 `0 1px 3px rgba(30,41,59,.06)`；
- 按钮/选项/列表行：`rounded-xl`；主按钮 `h-11~12 bg-brand-500 text-white font-semibold`；
- 答题选项：`px-4 py-3.5 rounded-xl border`，未选白底灰边，已选 `border-brand-500 bg-brand-50`，判分后绿/玫红加符号（✓/✗，不只靠颜色）；
- 成绩圆环：SVG `stroke-dasharray` 环形分（三端同一实现，仅尺寸不同）；
- 大数字：`font-extrabold tabular-nums`（倒计时/得分率/打卡天数）；
- 弱项条：得分率 <50% 玫红、50–70% 琥珀、≥70% 绿；
- 数据均为真实感 mock：年份 2010–2026、考点如「矛盾的同一性和斗争性」「新民主主义革命理论」、2026 新卷「客观 33 + 分析 5」。

## 2. 微信小程序端（proto-weapp.html，375×812）

遵守小程序设计规范的具体处理：
1. **原生导航栏 + 胶囊避让**：每页顶部为「状态栏 44px + 导航栏 44px」，标题居中；右上角保留 87×32 胶囊占位（`···｜◎`），任何可点内容不进入胶囊区；页面自定义头部一律不做沉浸式渐变，导航底色与页面同色（`#F5F7FB`）保证胶囊可读。
2. **tabBar ≤5 项**：4 项——工作台 / 真题 / 错题本（红点数字角标）/ 我的；高度 83px（49 + 34 安全区），激活态 brand-600。分析题背诵不占 tab，由工作台金刚区与任务卡进入（与现网动线一致）。
3. **无外链**：「我的」页无任何跳转外部的入口，客服提示使用小程序原生「联系客服」能力，邀请用「复制邀请卡」而非链接。
4. 交互从简：答题卡以页内折叠卡呈现（小程序少用手势抽屉），按钮式翻题；分享用「打卡分享图」（走小程序分享/保存相册）。

页面清单：首页工作台（倒计时+打卡、2026 新卷玫红横幅、今日任务 3 项、金刚区、弱项榜）→ 年份列表（2026 NEW/已模考得分率徽章/答题中续答）→ 答题页（多选示例、计时、标记、进度条、答题卡、交卷）→ 成绩页（68% 环形分、薄弱考点、错题重练入口、逐题解析）→ 错题本（今日到期横幅、筛选分段、玫红/琥珀左边条卡片）→ 分析题背诵（科目 chips、材料+设问、要点逐条遮盖「先想再看」、背会了/温习）→ 我的（额度、三格统计、邀请、列表行）。

## 3. 移动 APP 端（proto-app.html，375×812）

比小程序更自由的处理：
1. **沉浸式头部**：工作台/成绩页/我的采用 brand 渐变大头部（状态栏融入、底部 28px 大圆角、内容卡片 -mt 叠压浮起），信息层级更强。
2. **手势暗示**：金刚区横滑露半卡（swipe 暗示）；答题页标注「← 左右滑动切题 · 上拉呼出答题卡 ↑」；错题卡「左滑移出/收藏」；年份列表「上滑加载」；底部 Home Indicator 条。
3. **底部导航 5 项**：工作台 / 真题 / ⚡中央凸起快刷按钮（渐变圆钮，一键乱序快刷）/ 错题本 / 我的。
4. **APP 独有页**：
   - 学习报告：本周/本月分段，蓝底三格摘要（做题数/平均得分率/打卡天数）、近 7 日得分率柱状趋势（按语义色着色，今日高亮）、本周文字摘要 + 「按弱项组卷」CTA；
   - 推送提醒设置：每日刷题 / 错题到期 / 分析题温习 / 断签挽回 / 周报 5 个开关 + 免打扰时段，文案写明触发时间与条件。

## 4. 桌面端（proto-desktop.html，1440 宽）

宽屏利用策略：
1. **三栏骨架**：左侧 232px 固定导航（Logo、6 项菜单带角标、邀请卡、用户区）+ 主内容 + 右侧 320px 统计栏；主区最大宽 1208px。
2. **右栏统计常驻**：工作台右栏 = 打卡热力格（近 4 周）+ 弱项榜 + 背诵进度环；成绩页右栏 = 薄弱考点 + 历年模考成绩；错题本右栏 = 错题总数/导出 Anki + 按科目分布；背诵页右栏 = 进度环 + 题目列表（当前/背会/待温习状态）。
3. **答题页左题右卡**：左侧题干 + 选项（max-w-2xl 控行长）+ 上一题/交卷/下一题；右侧 sticky 答题卡（6 列格子：已答实心蓝/当前描边/标记琥珀/未答灰 + 图例 + 交卷按钮）。标注键盘操作：A-D 选择、←→ 切题、Enter 下一题。
4. **真题库**：年份 4 列卡片网格（2026 玫红 NEW 卡、得分率徽章、答题中续答），按年份/按考点分段切换；全局搜索框（题干/考点关键词）。

## 5. 工程落地建议

1. **token 落地**：三端共用 `DESIGN-SPEC.md` §0 的 tailwind.config；小程序端将 token 转为 WXSS 变量（`--brand-500` 等），APP 端（React Native/Flutter）建同名主题常量表。
2. **Web 端可直接复用**：`proto-desktop.html` 的三栏骨架可作为现网 `/app` 桌面布局升级版——viewHome→工作台、renderList→真题库、renderExam→左题右卡、renderResult→成绩页；≥1280px 启用右栏，<1024px 回退单栏（复用 proto-app 移动布局）。
3. **小程序**：原生 tabBar 4 项 + 自定义页面头不启用 `navigationStyle: custom`（避免胶囊适配成本）；分享图用 canvas 生成打卡卡片；提醒走订阅消息而非推送。
4. **APP**：答题页手势用横滑 PagerView + 底部答题卡 BottomSheet；推送 5 类 channel 对应设置页开关；学习报告周报可与推送「周报推送」打通。
5. **组件复用优先级**：答题选项、成绩圆环、弱项条、错题卡（左色条）、任务行 5 个组件三端结构完全一致，建议先做成跨端设计组件（Figma/代码双份），页面拼装即可。
