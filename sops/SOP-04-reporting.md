# SOP-04 汇报与验收

适用：所有角色向上汇报；project-lead 向 CEO/老板汇报。核心原则见 CHARTER §3、§5：**汇报后不等待回复，继续推进；无反馈视为默认认可。**

## 必报事件（三类）
1. **里程碑达成**：阶段完成、上线、交付
2. **方向变更**：偏离既定方案的决策（附理由与影响）
3. **重大风险**：可能导致延期/超支/法律风险的事项（附预案）

日常进度不单独报，合并进里程碑汇报或周报。

## 汇报格式
```
【结论】一句话说清发生了什么/决定了什么
【证据】PR/部署地址/截图/录屏/报告 链接
【下一步】默认将执行的动作（无异议即执行）
【需注意】不可逆动作/风险（如有，显著标注）
```

## 验收包标准（项目交付时）
- 可运行的成果（部署地址/安装包/仓库）
- 演示材料（录屏或分步截图）
- 需求逐条对照表（需求 → 实现位置 → 验证方式 → 状态）
- 已知问题与遗留项清单
