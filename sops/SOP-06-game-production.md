# SOP-06 游戏生产流程（Game Production Pipeline）

> 适用于所有游戏类项目（Daily Games 及后续新游戏）。由老板 Thomas 于 2026-08-02 指示确立：
> 团队构成参考专业游戏工作室，策划环节因 AI 策划能力短板需额外加强调研；
> 项目负责人只做制作人（推进/监控/迭代），目标是让团队持续生产更多、更好、更优质的游戏。

## 一、常设团队构成（每岗一个独立会话，可并行多实例）

| 部门 | 岗位 | 职责 | 角色模板 |
|---|---|---|---|
| 策划部 | 趋势研究员（常设） | 每周扫平台新榜/热榜、社媒热点、爆款拆解，产出选题报告 | market-researcher |
| 策划部 | 游戏设计师 | 玩法规则、数值难度、留存/分享钩子、原型验证 | product-manager / game-designer |
| 策划部 | 竞品拆解分析师（常设） | 深度拆解优秀产品的引导/爽感/情绪/传播/回访设计 | market-researcher |
| 美术部 | UI 设计师 | 视觉规范、界面设计、垂直切片品质标准把关 | ui-designer |
| 美术部 | 插画/动效 | 品牌图形、插画、微动效与完成时刻仪式感 | ui-designer |
| 程序部 | 客户端/服务端工程师 | 游戏逻辑、渲染、存档/排行/防作弊、平台适配 | fullstack-engineer |
| 音频 | 音效方案 | 版权库选配、关键时刻音效 | domain-expert |
| 质量 | 四道把关 | QA → 体验官 → 内部交叉测试 → 合规安全审计 | qa-engineer 等 |
| 发行运营 | 平台提交/SEO/数据分析 | 渠道分发、获客、留存/分享率数据反推策划 | growth-operator |

原则：
- 严禁工程师包办策划与美术；不熟悉领域实例化 domain-expert。
- 策划弱是 AI 团队的结构性短板，用「更多调研」补：趋势报告 + 竞品拆解常态化，选题必须有真实需求证据。

## 二、生产流程（每款新游戏必须走完，不得跳步）

1. **立项调研**：来自趋势报告/竞品拆解的选题，附流量证据与差异化钩子，一句话玩法（elevator pitch）。
2. **灰盒原型**（1-2 周内、无美术）：只验证「核心循环好不好玩」。体验官试玩给出 通过/砍掉 结论；不好玩就砍，不得带病进入下一步。
3. **垂直切片**：取一小段做到最终品质（美术+动效+音效+手感全到位），UI 设计师确认品质标准后冻结为该款验收线。
4. **量产开发**：按垂直切片标准铺全部内容；策划-美术-程序按短周期迭代。
5. **四道把关**：QA / 体验官（标准：「我会不会主动分享给朋友」）/ 交叉测试 / 合规安全，全部放行才可上线。
6. **上线发行**：按 SOP-03；平台提交、SEO、分享卡。
7. **数据迭代**：看次日留存、通关率、分享率；数据反推策划，进入短周期迭代循环。

## 三、验证与完成标准

- 所有「已修复/已上线」声明必须以线上 curl/UI 断言为完成标准，禁止以代码合并或任务勾选为准。
- 体验官复查以「会不会主动分享给朋友」为唯一标准。
- 视觉品质对标 NYT Games / neal.fun 精致度；移动端与无障碍为硬指标。

## 四、节奏

- 每周一份《趋势与选题报告》（TREND-REPORT-NNN.md）。
- 竞品深度拆解按需滚动（COMPETITOR-DEEPDIVE-NNN.md）。
- 制作人（项目负责人）按 SOP-04 逐轮向老板汇报，全程自动推进不等待确认。
