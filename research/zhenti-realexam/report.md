## 1. 真题文本获取渠道盘点

### 1.3 版本质量与校对策略
- 客观题题干与选项：各渠道文本一致性高（考生回忆版在考后 48h 内即收敛为统一版本）。
- 答案分歧点：多选题每年约 1-3 题在机构间存在争议，**必须以《考试分析》官方答案为准**；无官方答案的年份/题目至少三源交叉校验。
- 分析题（主观题）：题干为讲话/文件摘录+设问，文本可靠；「参考答案」网络流传版均为机构撰写，**不可直接使用**，需自写要点。
- 建议采购 2010-2025 各年《考试分析》纸质书（约 ¥500 一次性成本）作为终审依据；录入后按年抽样 100% 核对答案、20% 核对题干。

## 2. 合规边界结论

### 2.1 法律框架与判例（要点）
- 《著作权法》第 5 条：法律法规、国家机关决议决定命令等官方文件、单纯事实消息**不受**著作权保护——但**考试试题不属于第 5 条列举范围**，不能据此认为真题当然自由使用。
- 试题本身的版权属性：司法实践**不统一但总体倾向于「有独创性的试题构成作品」**。深圳中院菁优案再审（2020）判决书中表述「高考数学试题属于公有领域的内容」（个案表述）；而北京等地多起判例认定考试中心组织命制的试题/试卷可构成作品或汇编作品。考研政治命题主体为教育部教育考试院（事业单位），其对试卷主张权利存在法律可能性，但**公开检索未见教育考试院针对「政治真题在线刷题」商业使用的维权判例**；市场上粉笔、新东方、中国教育在线等长期公开提供全套政治真题刷题/下载，形成普遍行业惯例，实际执法风险低。
- **确定的高风险点（有生效判决）**：试题中**嵌入的第三方已发表作品**。北京西城法院 2007 年判决 6 家出版社汇编高考语文真题成书（含胡某文章）构成侵权——商业性汇编出版真题时，题目内嵌的他人文章需获授权。对考研政治而言，题目引用对象主要是领导人讲话、党政文件、时事新闻（官方文件与单纯事实消息不受保护），**极少嵌入私人文学作品**，该风险显著低于语文/英语科目；仅需注意个别引用诗词、当代学者著述、新闻特稿原文的题目。
- **解析的版权：明确受保护**。菁优案确立：解题思路分析、考点点评等只要有独创性即构成作品。因此**任何机构（新东方/中公/肖秀荣等）撰写的解析、参考答案组织语言、答案要点归纳均不可复制**。我们自写/AI 生成解析的规避方案成立且必要——AI 生成时不得以机构解析为直接输入源改写。

### 2.2 能做 / 不能做 / 需注意清单
**能做**
1. 录入 2010–2025 客观题（单选/多选）题干、选项、官方答案，在线刷题（含免费+会员场景）
2. 自写/AI 生成全部解析与考点标注（以教材、考纲、官方《考试分析》的知识点为依据，不以机构解析为底稿）
3. 分析题保留题干+设问，配我们自写的「参考要点+自评量表」（延续现有材料分析题自评模式）
4. 标注「真题·20XX 年第 X 题」事实性来源信息

**不能做**
1. 复制任何机构的解析、答案详解、要点归纳原文（哪怕改几个字）
2. 整册复制《考试分析》的命题思路/统计数据文字
3. 抓取需付费/登录的题库内容（粉笔题库、掌上考研等）
4. 宣称「官方授权」「官方真题库」等误导性表述

**需注意**
1. 逐题排查引用第三方版权材料的题目（诗词节选、学者论著、署名新闻特稿），此类题（估计 <2%）改写材料或不入库
2. 多选争议题以官方《考试分析》为准并在库内记录 `answer_source`
3. 保留下架预案：若收到教育考试院权利主张，真题模块可整体切换为「按真题逐题改编的仿真题」（我们已有 AI 改编管线，改写题干表述+同考点重构选项即为新作品）
4. 产品文案用「历年真题练习」，避免使用可能构成商标的机构品牌词

## 3. 每年题型结构与总题量估算

2010 年考纲改革后结构稳定至今（满分 100，180 分钟）：
| 题型 | 题号 | 数量 | 分值 |
|---|---|---|---|
| 单项选择 | 1–16 | 16 | 16×1=16 |
| 多项选择 | 17–33 | 17 | 17×2=34 |
| 材料分析 | 34–38 | 5 | 5×10=50 |

- 16 个年份（2010–2025）总计：**608 题**（客观题 528 = 单选 256 + 多选 272；分析题 80）
- 科目分布（客观题大致）：马原 ~24%、毛中特 ~30%（含习概后拆分）、史纲 ~14%、思修法基 ~16%、形势与政策及当代 ~16%
- 注意：形势与政策题（每年约 4-6 题客观 + 当代分析题）**时效性强**，建议单独打 `is_current_affairs` 标记，默认不进常规组卷，仅进「真题原卷模式」

## 4. 建议入库 Schema（D1）

```sql
CREATE TABLE real_exam_questions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  year INTEGER NOT NULL,              -- 2010..2025（考试届别年）
  number INTEGER NOT NULL,            -- 1..38 原卷题号
  section TEXT NOT NULL,              -- 'single' | 'multiple' | 'analysis'
  score REAL NOT NULL,                -- 1 / 2 / 10
  subject TEXT NOT NULL,              -- 'mayuan'|'maozhong'|'shigang'|'sixiu'|'shizheng'
  stem TEXT NOT NULL,                 -- 题干（分析题含材料）
  options_json TEXT,                  -- [{key:'A',text:...}]，分析题为 NULL
  answer TEXT,                        -- 'B' / 'ABD'；分析题为 NULL
  answer_source TEXT NOT NULL,        -- 'kaoshifenxi'|'multi_source'|'disputed'
  analysis_points_json TEXT,          -- 分析题：我们自写参考要点
  explanation TEXT,                   -- 我们自写/AI 生成解析（客观题）
  kp_ids_json TEXT NOT NULL,          -- 映射到我们 109 考点的 id 数组（可多个）
  kp_confidence TEXT NOT NULL DEFAULT 'auto', -- 'auto'|'reviewed'
  is_current_affairs INTEGER NOT NULL DEFAULT 0,
  third_party_material INTEGER NOT NULL DEFAULT 0, -- 引用第三方版权材料标记
  status TEXT NOT NULL DEFAULT 'active', -- 'active'|'excluded'|'rewritten'
  created_at TEXT DEFAULT CURRENT_TIMESTAMP,
  UNIQUE(year, number)
);
CREATE INDEX idx_req_kp ON real_exam_questions(subject, section);
```

要点：
- `kp_ids_json` 用 AI 初标 + 人工/子会话复核（`kp_confidence` 流转），即可打通「真题 × 我们 109 考点」双向：考点页展示历年真题、真题解析反链考点、组卷时按考点混编真题+AI 仿真题
- `answer_source` 与 `third_party_material`、`status` 三个字段落实第 2 节合规策略
- 展示层统一标「20XX·真题」徽标，与 AI 仿真题明确区分（信任卖点）
