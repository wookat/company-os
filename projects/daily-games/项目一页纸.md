# 项目一页纸：Daily Games 每日游戏矩阵（代号 DG）

| 项 | 内容 |
|---|---|
| 项目名 | Daily Games 每日游戏矩阵（英文市场网页游戏群，落地于 zalize-games 底座 / zalize.com 子域或独立游戏域名） |
| 一句话目标 | 为英文市场休闲玩家（上班摸鱼/每日仪式感人群）提供一组「每日一题、点开即玩、可炫耀分享」的轻量网页游戏，6 个月内做到稳定广告收入（首笔收入 ≤8 周，月收入 $500+ 为 M4 达标线） |
| 范围（本期） | ① 并行开发 6-10 款每日制轻量网页游戏（词类/数字/合成/地理/图形推理等已验证品类微创新 + 1-2 款 AI 原生玩法：每日 AI 案件/LLM 无限合成）；② 统一门户与交叉导流、统一分享格式（emoji 结果矩阵）、统一每日种子与排行榜；③ 提交 Poki/CrazyGames 分发 + 自有站 SEO；④ 广告变现（激励视频+展示位）+ 后续去广告轻内购 |
| 非目标（明确不做） | 不做买量投放；不做微信小游戏（第二阶段另立项）；不做 Steam/iOS 版本；不做重美术/3D/多人实时；不做账号强制注册；不做 IAP 数值运营盘 |
| 里程碑 | M1（2 周）：骨架可跑——门户+首批 3 款游戏可玩、每日种子/分享/统计管线通；M2（4-5 周）：主流程完整——6-10 款全部上线自有站，SEO 基础就绪，提交 Poki/CrazyGames 审核；M3（6-7 周）：四道把关通过（QA/体验官/交叉测试/合规安全）；M4（8-12 周）：平台过审上线+竞品对标达标，产生首笔广告收入，转入 SOP-05 运营迭代 |
| 组队名单 | product-manager×1、spec-writer×1、tech-lead×1、ui-designer×1、ux-researcher×1、frontend/fullstack-engineer×6-10（每款游戏一实例并行）、qa-engineer×2、user-experience-officer×1、code-reviewer×1、compliance-counsel×1、seo-specialist×1、data-analyst×1（运营期） |
| 外部资源清单 | ① Google AdSense（或 AdinPlay）账号+收款信息——上线后变现用；缺口期：先用占位广告位/平台分成先行 ② Poki/CrazyGames 开发者账号（免费注册，若需你名义主体信息再找你）③ 域名：默认复用 zalize.com（已有 Cloudflare 权限），无需新购。以上均不阻塞开工 |
