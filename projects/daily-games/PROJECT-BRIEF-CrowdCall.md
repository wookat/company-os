## 1. 玩法一句话

**每天 5 道「大多数人会怎么答？」，押注昨天全体玩家的真实答案分布——猜中人心得分，你今天的回答就是明天别人的题目。**

## 2. 核心循环

```
今日局（2-4 分钟）：
  第 1-5 题，每题两段：
    a) 回答段：先自己作答（投票题选选项 / 估算题拖滑条 / 开放题打一个词）
    b) 押注段：预测「昨天玩家的答案分布」——
       投票题：把 100 筹码分配到各选项（按与真实分布的贴近度得分）
       估算题：猜中位数落点（按误差百分比得分）
       开放题：Family Feud 式猜 Top5 高频词（命中名次越高分越高，逐条揭示"Survey says…"）
  → 即时揭示昨日真实分布 + 你的分位数（击败 X% 预测者）
  → 总分结算 + emoji 分享卡（🟩命中/🟨接近/🟥翻车 ×5）+ streak
  → 钩子：「你的回答已进入明日题池」+ 明日题类预告
数据飞轮（服务端每日 0 点 UTC）：
  今日回答池 → LLM relay 清洗聚类（去污/合并同义/截断长尾）→ 生成明日题目的标准答案分布
```

关键设计判断：**「先答后押」**是本品类灵魂——先答保证数据池新鲜（飞轮进料），后押制造「我 vs 人群」的认知张力；两段合一题内完成，无需等待感。

## 3. 数值 / 留存 / 分享钩子

- **数值**：单题满分 200（押注 0-150 + 回答与主流一致的「共识奖励」0-50，开放题反转为「独特但被≥3 人选中」的黑马奖励——避免全员抄最平庸答案导致题池退化）。日满分 1000；难度节奏：周一 2 投票+2 估算+1 开放（易）→ 周末 1+2+2（开放题多=难）。
- **留存**：streak + 一周日历点亮（COMPETITOR-DEEPDIVE Top10 #3 组件）；「明日预告」悬念（今晚 8 点后显示明日题类+一条模糊线索）；archive 不可补玩（分布是时效数据，缺席即错过——稀缺性反而是本品类独有的留存杠杆，与其他 12 款相反，需在 FAQ 明示）。
- **分享钩子**：①emoji 网格 + 「我击败了 X% 的读心者」分位数行（平台组件首个消费方）；②单题「翻车卡」——你的押注 vs 真实分布对比图，惨败比胜利更可传播（TREND-001 失败可分享原则）；③「我的答案上榜了」——若你昨天的开放题答案进入今日 Top5，通知+专属分享卡（UGC 荣誉感，零成本病毒环）。
- **AI 差异化**：结算页 AI 读心报告一句话（「你高估了人类对菠萝披萨的宽容度」），复用 Heatword 已验证的 LLM 锐评组件。

## 4. 服务端聚合架构要点（Cloudflare 栈，零新增资源）

- **存储**：D1 两张核心表 `questions(day, type, prompt, answer_dist JSON, source_day)`、`responses(day, qid, client_id, answer, bet JSON)`；KV 缓存当日题目与昨日分布（读多写少，D1 只承写入与日终聚合）。
- **写入路径**：POST /api/answer 幂等（client_id+qid 唯一），限每 IP 每题 1 次 + Turnstile 免费人机验证（防刷分布——Center This Div 案例证明爆红后 2 小时内必有人刷）。
- **日终聚合（Cron Trigger 00:00 UTC）**：SQL 聚合投票/估算题分布 → 开放题原文送 LLM relay 清洗聚类（prompt 固定+人工抽检队列）→ 写入明日 `questions.answer_dist` → 预热 KV。聚合是纯批处理，无实时扇出，Worker 免费额度内可跑（推断，置信度高；灰盒实测确认）。
- **结算即时性**：玩家押注的是「昨日」分布（已冻结数据），所以**当场开盘**，无需等待——这是对 Hold The Line「次日才知输赢」的体验改良。
- **冷启动种子**：上线前 14 天题目由 LLM 合成分布 + 站内其他 11 款结算页嵌入单题「热身投票」预收真实数据；UI 标注「早期数据 · N 人参与」，N<200 时只显示分布不显示分位数（沿用 DropStack 冷启动教训，COMPETITOR-DEEPDIVE §三）。

## 5. 灰盒验收线（1 周，不带美术）

- D1-2：D1/KV 表结构 + 答题/押注 API + Cron 聚合（LLM 聚类先用固定 mock）；D3-4：Svelte 灰盒前端（三题型交互+结算）；D5：LLM 聚类真管线+30 道种子题；D6-7：≥10 人两日连测（必须跨两天，验证飞轮转起来）。
- **量化验收线（不过线即砍）**：
  1. 无教学 30 秒内完成第一题（三题型交互自解释）；
  2. 单局中位时长 2-4 分钟，完局率 ≥80%；
  3. 次日回访 ≥50%（10 人中 ≥5 人第二天主动回来看「我的答案有没有上榜」）；
  4. 至少 3 人未经提示主动把分享卡/翻车卡发给别人；
  5. 开放题聚类人工抽检 30 条，错误合并/漏污 ≤2 条；
  6. 刷分测试：脚本提交 100 次仅计 1 次。
- 灰盒判定金句：测试者说出「不可能吧，居然有 X% 的人选这个？！」——惊讶即产品。

## 6. 合法克隆边界（红线声明）

- **机制不受版权保护，表达受**：我们借鉴的是「预测群体答案」抽象机制（Family Feud/Google Feud/Hold The Line/Top 5 共用），不复制任何一家的：名称/商标（不用 "Feud"、"Survey Says" 作为产品名或功能名——"survey says" 在 Fremantle 的 Family Feud 商标语境下有风险，UI 文案改用 "The crowd said…"）、题库内容、美术/音效/主持人形象、代码。
- 题目 100% 自产（LLM 生成 + 玩家答案飞轮），无第三方数据集；玩家答案入池在隐私政策中明示（匿名聚合、不可回溯个人）。
- 无真钱、无兑换、筹码纯虚拟且不可购买——不构成赌博；措辞避免 bet/betting，对外用 predict/call。
- 上线前 compliance-counsel 过一遍：商标检索（CrowdCall 名称）、隐私条款增补、Fremantle 商标雷区复核。
