## 1. 玩法逐层拆解（基于 2026-08-01 实玩反推）

### 1.1 核心循环
输入任意单词 → 返回与目标词的语义距离排名（#1 = 目标）+ 冷热渐变条 → 根据梯度调整方向继续猜 → 无限次直到 #1。每次猜测 2 秒内闭环，思维路径实时可视化。

### 1.2 规则
- 距离 = 预计算 embedding 相似度排序（对全词表离线排一次，运行时查表——零推理成本）。
- 无失败状态：可无限猜、可放弃看答案（放弃也给分布复盘）——挫败感极低。
- 提示机制：给出比当前最好名次更近的一个词（激励视频兑换位）。

### 1.3 数值曲线
- 难度 = 目标词的「语义邻域密度」：具体名词（banana）易，抽象词（justice）难。
- 原版按周节奏混排难易；分享卡显示猜测次数 + 🟩🟨🟥 分布（<300 绿 / <1500 黄 / 更远红），次数本身成为谈资。

### 1.4 关卡与难度
- 每日一词 + 免费 archive 日历（可补玩历史期号，SEO 长尾极强）+ Unlimited 模式承接。

### 1.5 留存与分享钩子
- streak + 期号分享卡 + archive 补玩；姊妹游戏互导。缺：无全球实时对比（你第几个解出）、无 AI 人格。

### 1.6 变现位
- 展示广告（猜测列表下方原生位）+ 激励视频换提示 + 矩阵导流。

## 2. 我方差异化改良（2-3 个）

1. **全球战况直播条（S）**：页面常驻「今日已有 N 人解出 · 中位 42 猜 · 你当前第 #猜」，解出瞬间显示「你是今日第 N 个 🌍」。把单机猜词变成「全球同题赛马」，直击 Contexto 最大空位（社会锚点），且方案与 COMPETITOR-DEEPDIVE-001 Top10 第 1 项同源复用。
2. **AI 毒舌解说（S，我方 LLM relay 现成）**：每 10 猜触发一句 AI 对你猜测轨迹的锐评（「从 ocean 跳到 democracy？你的脑回路值得研究」），通关后生成「思维路径一句话总结」进分享卡——对标 Yapword 的 AI 人格路线，全品类无人做在 Contexto 形态上。
3. **双词模式周末赛（M，后置）**：周末目标为词对（如 hot+dog），距离取两词最小值，解出需先意识到「有两个目标」——原创变体，作为周末流量峰值的差异化谈资。

## 3. 灰盒原型验证方案（1 周）

- D1-2：词表（英语常用 30-50k 词，自建/开源词频表）+ 开源 embedding（如 gte/bge 类）离线算全排序，Worker 查 KV 返回名次。
- D3：Svelte 前端灰盒：输入框+名次列表+渐变条，无美术。
- D4：难度标定：对 100 个候选目标词跑「模拟玩家」（贪心爬梯算法）估平均猜测数，建立易/中/难分档。
- D5-7：10 人测试，验收：①无教学 30 秒上手；②中位通关 20-60 猜（太快没谈资、太慢流失）；③放弃率 <30%；④AI 锐评被至少 3 人主动截图。
- 灰盒判定标准：测试者通关后第一反应是「你猜了多少次？」——谈资即产品。

## 4. 工程量：**S+**

前端极简 + 一次性离线 embedding 管线 + 现有 Worker/KV/LLM relay 全复用。四个目标中工程量最小、与现有矩阵协同最强；风险在词表质量与难度标定（已在灰盒 D4 前置验证）。
